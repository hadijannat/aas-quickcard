## Extension Name
AAS QuickCard

## Short Description (132 characters max)
Turn AAS (Asset Administration Shell) JSON into human-friendly equipment cards with manuals, safety docs, and contacts.

## Detailed Description

**AAS QuickCard** transforms complex Asset Administration Shell (AAS) JSON data into clear, actionable equipment cards that anyone can use.

### Who is it for?

- **Maintenance Technicians**: Quickly find manuals, service contacts, and equipment details
- **Operators**: Access safety documentation and operating instructions
- **Quality Inspectors**: View certificates and compliance documents
- **Procurement/Service Desks**: Get manufacturer info and support contacts

### Key Features

📖 **Read from Any Page**: Click "Read this page" to extract AAS JSON from the current tab

📦 **Upload AASX Files**: Load AASX packages directly from your computer

📋 **Paste JSON**: Copy-paste AAS JSON for instant viewing

👤 **Role-Based Views**: Switch between Operator, Maintenance, Quality, and Procurement views to see relevant information

📄 **Documents at a Glance**: Browse manuals, safety sheets, datasheets, and certificates with one-click access

📞 **Quick Contacts**: Call, email, or visit support links directly from the card

⭐ **Favorites**: Pin frequently accessed assets for quick reference

📱 **QR Labels**: Generate QR codes for asset identification

📋 **Support Tickets**: Copy formatted asset information for support requests

### Privacy First

AAS QuickCard processes all data locally in your browser. No data is sent to external servers. No tracking. No analytics.

### Industry 4.0 Ready

Built for the digital transformation of manufacturing and industrial operations. Compatible with IDTA-standard AAS formats, including the Nameplate and VDI 2770 documentation submodels.

### Demo Mode

Try it instantly! Click "Demo Mode" to see AAS QuickCard in action with sample data - no external access required.

## Additional Information

### Single Purpose Description
This extension displays equipment information from Asset Administration Shell (AAS) JSON in an easy-to-read card format.

### Permission Justifications

- **sidePanel**: Core functionality - displays the QuickCard interface
- **storage**: Saves user favorites and settings locally
- **scripting**: Reads AAS JSON from web pages when user clicks "Read this page"
- **activeTab**: Temporary tab access only when user clicks the extension
